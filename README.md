## Lessons Learned

During this week, I learned how CSS controls the presentation and layout of a webpage. I learned how to use CSS variables to create a consistent design system and how the box model controls the space around elements.

I also learned how Flexbox can be used to arrange and align items, while CSS Grid is useful for creating structured layouts with rows and columns.

The most important lesson for me was mobile-first responsive design. I learned that a website should first work well on a small screen and then be enhanced for tablets and desktop screens using media queries.

I also learned that keyboard accessibility is important, so links and buttons should have visible focus states rather than having the focus outline removed.
